## Cross-cutting findings (all acts)

1. **Most MP sources are scans:**
   - phone scans (wages)
   - copier fax-G4 (Lok Seva, Sanhita)
   - gazette scans (SLSA)

   OCR (W0.5) is on the critical path. It must accept **CCITT G4** images and gray JPEG; the test set should include G4 pages.
2. **"Born-digital" Hindi text is often corrupt.** Three patterns seen:
   - (a) Latin OCR layer (0% Devanagari): caught by the new check
   - (b) ि extracted as ध (MP RTI rules, 2014 converter): not caught
   - (c) Latin-extended glyphs inside Devanagari (Excel → Print to PDF, Lok Seva list): not caught

   → W1.1 needs a **text-quality gate** (e.g. hit-rate on a list of very common Hindi words) before trusting any Hindi text layer.
3. **Official portals need special handling:**
